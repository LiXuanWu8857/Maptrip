# 搜尋功能（Search）— 功能與交接

**現況版本：v1.1.434**。給下一個 session 接手用：把「搜尋」這一塊的所有相關檔案、
UX 流程、對外 API、與其他模組的接點、外部服務、血淚坑、測試、待辦，一次列清楚。

> 一句話：右下角 🔍 FAB 是一個 speed-dial 選單，彈出 6 個選項（找客熱區／加油站／
> 停車場／便利商店／醫院／搜尋地址）。前 5 個「找附近 POI」走 `nearby.js`（Overpass），
> 「搜尋地址」走 `addr-search.js`（Nominatim），搜到的點都釘在**地圖**上，點釘子→
> `nav.js` 導航選單（Google／Apple 地圖）。找客熱區另走既有 `hotspots.js`。

## 2. UX 流程

1. 點右下角 🔍 FAB → `MaptripSearchMenu.toggle()` → 往上長出 6 顆 pill（由下往上 stagger 動畫）。
2. 點某顆 pill → `pick(kind)`：
   - `hotspot` → `window.openHotspots()`（找客熱區面板）
   - `address` → `MaptripAddr.open()`（頂部搜尋框）
   - `fuel`/`parking`/`store`/`hospital` → `MaptripNearby.run(kind)`
3. **找附近**：Overpass 查半徑 3km 內的 POI → 依直線距離近→遠編號 ①②③…釘在地圖、
   自動 `fitBounds`。此時右下角 🔍 FAB **變成紅色 ✕**（`#hotspot-btn.nb-clear`）＝清除鈕；
   再點它＝清掉釘子、還原 🔍（`MaptripSearchMenu.toggle` 有分流：有結果時點 FAB＝清除，不開選單）。
   出結果 **2 分鐘**沒動作自動清除。便利商店釘子標有無廁所（🚻）。
4. **搜尋地址**：輸入地址/地點名 → Nominatim → 地圖跳到該處放紅標、`setView` zoom 16。
5. 點任何釘子/紅標 → `MaptripNav.open(name, lat, lng, note)` → 底部彈出「Google 地圖／
   Apple 地圖」選單 → `window.open(url,'_blank')` 交給系統開對應導航 App。

## 3. 各模組詳解

### 3.1 `search-menu.js`（MaptripSearchMenu）
- `ITEMS`：6 顆 pill 的設定（k/icon/label）。要加/改選項改這裡。
- 對外：`toggle() / open() / close()`；`_pick/_items/_diag` 供測試。
- **FAB 變 ✕ 的分流**：`toggle()` 開頭先問 `MaptripNearby.hasResults()`，有結果就 `MaptripNearby.close()`（清除）而**不**開選單。
- **lazy build**：首次 `open()` 才建 DOM＋注入 CSS（`_built` 旗標）；無 boot init。
- **動畫**：pill `transform-origin:100% 100%`（右下角固定、往上長），nth-child 1→6 遞增 `transition-delay`；收合時反向 delay＝倒帶收回 FAB。收合總長 `COLLAPSE_MS=460`。
- **展開時淡出右側 FAB**：`body.mt-search-open` 把 `#locate-btn/#compass-btn/#hotspot-btn/#booking-btn` 透明化（畫面乾淨、選單像從「我的位置」長出）；收合後等 `COLLAPSE_MS` 才淡回（`_fabTimer`）。

### 3.2 `nearby.js`（MaptripNearby）
- `CATS`：4 類（fuel/parking/store/hospital）的 Overpass 選擇器、標題、圖示、釘色、空結果文案、是否備註廁所（`wc`）。要加類別改這裡。
- `RADIUS=3000`（3km）、`TOP_N=12`、`AUTO_MS=120000`（2 分自動清）。
- **搜尋中心**：地圖當下中心 ＋ GPS 一起（union，兩者 <300m 只用一個省流量）；距離基準優先用 GPS（＝離你多遠）。「把地圖移到哪就搜哪」。
- **Overpass 多鏡像並行競速**（`MIRRORS` 4 個，先回先用；全掛才算失敗）——舊版序列會卡 20 秒才換。
- 便利商店：`STORE_BRAND` 後備（OSM 常只給 name 沒給 shop=convenience）＋ `STORE_EXCLUDE`（濾掉蝦皮店到店等純寄取貨點）；`_toilet()` 讀 OSM toilets 標籤。
- 對外：`run(kind) / close() / clearMap() / hasResults() / CATS`；純函式 `_haversine/_fmtDist/_name/_toilet/_parse/_overpassBody/_note/_drawMap/_fetchOverpass`。

### 3.3 `addr-search.js`（MaptripAddr）
- Nominatim `/search`（`format=jsonv2&limit=1&countrycodes=tw&accept-language=zh-TW`），15 秒逾時（AbortController）。
- `open()` 頂部搜尋框 → `submit()` 地理編碼 → `setView` zoom 16 ＋ `dropMarker` 紅標（`.mt-addr-pin`）→ 點標記 `MaptripNav.open`。
- 對外：`open/close/submit/geocode`；純函式 `_short`（display_name 取前兩段當簡稱）。
- 依賴：`window.__mtLive.map`、`window.L`、`MaptripNav.open`、`window.toast`。

### 3.4 `nav.js`（MaptripNav）——共用導航選單
- 純函式：`googleUrl(lat,lng)`＝`maps/dir/?api=1&...&travelmode=driving`、`appleUrl`＝`maps.apple.com/?daddr=...&dirflg=d`。
- **刻意用通用 https 網址而非 App scheme**：有裝 App 就開 App、沒裝開網頁，永遠成立，且不必動 `Info.plist` 的 `LSApplicationQueriesSchemes`。
- `open(name, lat, lng, note)`：底部彈出 sheet，`note` 選填（距離／廁所）。
- `window.open(url,'_blank')`：WKWebView 對 `_blank` 交給系統開地圖 App。
- 對外：`open/close/googleUrl/appleUrl`。**地圖上的 POI（transit 圖層）也呼叫它**，改 nav 要注意不只搜尋在用。

## 5. 血淚坑 / 設計要點（勿隨意動）
1. **FAB id 沿用 `hotspot-btn`**：不是打錯。原本這顆是「找客熱區」🔥，改成搜尋 🔍 時沿用 id，
   才能保留既有 `.hs-spin`（載入轉圈）與 desktop-mode 隱藏規則。`.hs-flame` 內容改成 🔍。
2. **搜尋選單按鈕高亮錯位（iOS）**：speed-dial 動畫中用 `:active` 會把深色畫到「手指按下當下」
   那顆、可能與最後 click 到的不同（iOS 座標/時序差）→「按停車場卻加油站變深色」。解法：
   關掉 `-webkit-tap-highlight-color`、不用 `:active`，改由 click handler 標 `.picked` 在**真正被點到**那顆；
   收合中 pill `pointer-events:none`（手指還按著時下面那顆不會滑到手指下被標 active）。真機黑盒子
   `_diag`（touchstart target vs elementFromPoint under，MISMATCH 記進 `__mtLog`）可查座標錯位。
3. **z-index**：`#mt-sm`=22 / backdrop=21，要壓在底部列（20）之上，否則最下面那顆 pill 被底部列蓋住按不到。
4. **「找附近」結果的清除＝右下角 FAB 變 ✕**，不是另外一顆鈕：靠 `search-menu.toggle` 的
   `hasResults()` 分流 ＋ `nearby._setClearMode`（`#hotspot-btn.nb-clear::after{content:"✕"}`）。改任一邊要對齊。
5. **搜尋中心 union（地圖中心＋GPS）**：使用者可能在 A 地、但把地圖滑到 B 地想找 B 的加油站 → 兩處都搜。

## 7. 待辦 / 可改進
- 找附近**沒有底部清單**（刻意，地圖優先）；若要回清單可加，但注意別撞 ✕ 清除流程。
- Overpass 尖峰偶爾全鏡像慢 → 可考慮加本地快取（同中心短時間內重用）。
- Nominatim 單筆結果（`limit=1`）：模糊地名可能跳錯點；要更準可改多筆候選讓使用者選。
- 「醫院」只在 FAB 選單、app.js L966-970 的 ☰ 分流**沒有** hospital 分支（☰ 走不到醫院，只 🔍 走得到）——若要補，app.js 加一條 `else if (action==='hospital')`。
- 地址搜尋的紅標與「找附近」的釘子是兩套 marker，彼此不互清；通常無妨，但大量使用可考慮統一清除。
