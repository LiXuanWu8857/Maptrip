## 2. 資料模型（一筆預約 object）

```js
{
  id,                       // 字串（新增時 save() 補時間戳 id）
  pickupTime,               // ms epoch，儲存時 5 分鐘進位（Math.round(ms/300000)*300000）
  pickup: { text, lat, lng },        // 出發地（lat/lng 目前多半 undefined，見待辦）
  dests: [ { text, lat, lng }, ... ],// 下車點陣列，最多 MAX_DESTS=4；最後一個＝目的、其餘＝中途
  name, phone, lineName, note,       // 稱呼 / 電話 / LINE 名 / 備註
  reminders: [30, 60, ...],          // 提醒（分鐘，提前量）
  status,                   // 'pending'(待確認) | 'confirmed'(已確認) | 'done'(已完成) | 'cancelled'
  confirmedAt, doneAt       // 標記時間戳
}
```
※ 舊欄位 `dest`（單一）已淘汰，`_saveForm` 會 `delete b.dest`，一律用 `dests` 陣列（`_destsOf(b)` 相容讀取）。

## 3. 儲存與同步（血淚坑都在這）

- **本機**：localStorage `maptrip_bookings`（`_persist/_loadLocal`）。換帳號由 sync.js 清（同記帳/行程隔離）。
- **雲端**：Firestore `users/{uid}/bookings/{id}`，每筆一份。
  - `save(b)` → `_persist` + `MaptripSync.writeBooking(b)`（merge）
  - `remove(id)` → `_persist` + `MaptripSync.deleteBooking(id)`
  - `set(list)`（onSnapshot 進來）→ 覆蓋本機 `_list` + 重繪（**不回寫雲端**，避免迴圈）
  - **Firestore 規則**：需允許司機本人讀寫自己的 `users/{uid}/bookings/**`。若規則沒部署＝靜默沒上雲（UI 樂觀更新仍看得到）。
- **開始/完成綁定**：
  - `maptrip_active_booking`（localStorage）＝精準記住「這台正在跑哪一筆」，App 重載後 `init()` 還原。
  - 讀 recorder 的 `maptrip_active`（`{id,startTime,coords}`）取跑車行程起始時間，供 **±20 分後備配對**。

## 5. 三大流程

1. **清單/表單**（滿版 overlay `#bk-list` / `#bk-form`，非底部 sheet）
   - 依日期分組、由近至遠；已完成縮成小方塊排最下面、由遠至近（`_renderList`）。
   - 卡片 `_cardHtml(b, activeId)`：標題（時間/日/狀態膠囊，**編輯在右上角** `.bk-edit-corner`）、
     路線（出發/中途/目的＋圓點，導航鈕在地址右邊 `.bk-routewrap`）、提醒方塊、
     **主要列單顆全幅**（未跑車→「開始」藍 `.bk-start-btn`；跑這筆中→「完成」綠 `.bk-finish-btn`）、
     **次要列同一排**（撥號/傳確認/標記已確認/直接完成，`.bk-sec` nowrap）。
2. **地圖橫幅**（`#bk-onmap`）：預約時間 `≤30 分`（`ONMAP_WIN`）出現，過時 15 分內仍顯示（`ONMAP_GRACE`）；
   跑車中改成整卡藍、併時間/距離（`_recCardHtml` + `_syncRecInfo` 每秒更新）。`_onMapBlocked()` 決定哪些畫面不顯示。
3. **開始 ⇄ 完成（跟主頁地圖連動）**
   - `startFromList(id)` → `startFromMap(id)`：擋重複錄製、`_setActiveBk(id)`、`global.startTrip()`、關清單。
   - `finishFromList(id)`：標記該筆 done、`_setActiveBk(null)`、關清單、`global.endTrip()` → **`showFareDialog` 自動跳車資輸入**（跟主頁地圖同一條路，車資記進今日行程/收支）。
   - 「是哪一筆」＝ `_pickActiveId`：精準 `boundId` 優先；否則用行程起始時間 **±20 分**配對最近的未完成預約（涵蓋「從地圖底部開始」「App 重載綁定遺失」）。

- 包 `@capacitor/local-notifications`（`package.json` 釘 `^6.1.0`，對應 Capacitor 6）。
